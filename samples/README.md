# DocForge AI Samples

Use this folder for tiny, safe demo PDFs only.

Recommended local sample name:

```text
samples/sample.pdf
```

Guidelines:

- Do not commit private customer PDFs.
- Do not commit internal company reports, contracts, invoices, or confidential manuals.
- Keep real customer files in a separate private folder outside the repo.
- If you add a sample PDF to test locally, the smoke test will use `samples/sample.pdf` when it exists.
- Only commit a PDF here if it is tiny, public, and safe to share.
