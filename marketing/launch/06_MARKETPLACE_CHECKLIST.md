# Marketplace Launch Checklist

Use this checklist before publishing RelayWorks AI Document Processing Kit on Gumroad, a personal site, GitHub Releases, or any software marketplace.

## Product Package

- [ ] Confirm repository builds from a clean checkout.
- [ ] Confirm backend syntax check passes.
- [ ] Confirm backend job tests pass.
- [ ] Confirm frontend typecheck passes.
- [ ] Confirm frontend production build passes.
- [ ] Confirm Marker installation instructions are clear.
- [ ] Confirm `marker_single --help` requirement is visible.
- [ ] Confirm no private PDFs are committed.
- [ ] Confirm generated storage outputs are not included unless intentionally packaged as proof.
- [ ] Confirm launch screenshots are included.
- [ ] Confirm demo video file is final if used.
- [ ] Confirm sample PDF redistribution rights before bundling any sample document.

## Legal And License

- [ ] Replace draft `LICENSE.md` with final license terms.
- [ ] Decide personal, commercial, team, and agency/client-work rights.
- [ ] Define update period.
- [ ] Define support scope.
- [ ] Define refund policy.
- [ ] Review third-party dependency licenses.
- [ ] Review Marker licensing and installation terms.
- [ ] Review screenshot/sample asset rights.
- [ ] Add final copyright notice.
- [ ] Make clear that the product is not open source unless that is intentional.

## Listing Assets

- [ ] Final product title selected.
- [ ] Short description ready.
- [ ] Long description ready.
- [ ] Feature bullets ready.
- [ ] Requirements listed.
- [ ] Known limitations listed.
- [ ] Refund policy listed.
- [ ] License summary listed.
- [ ] SEO keywords added.
- [ ] Screenshots uploaded in recommended order.
- [ ] Demo video uploaded if available.
- [ ] GitHub repository link added if appropriate.
- [ ] Documentation link added.

## Pricing

- [ ] Personal license price selected.
- [ ] Commercial license price selected.
- [ ] Team license price selected.
- [ ] Early buyer discount decided.
- [ ] Launch coupon created if used.
- [ ] Price anchoring copy prepared.
- [ ] License-tier differences clearly explained.

## Technical Proof

- [ ] Screenshot: homepage.
- [ ] Screenshot: goal selection.
- [ ] Screenshot: conversion complete.
- [ ] Screenshot: Markdown output.
- [ ] Screenshot: structured JSON.
- [ ] Screenshot: download package.
- [ ] Screenshot: FastAPI endpoints.
- [ ] Screenshot: extracted images.
- [ ] Install proof linked.
- [ ] Validation commands documented.

## Marketplace Setup

- [ ] Product file uploaded.
- [ ] ZIP contents reviewed.
- [ ] Duplicate/generated junk removed from ZIP.
- [ ] `.env` files excluded.
- [ ] Private storage outputs excluded unless intentionally included.
- [ ] Gumroad product URL checked.
- [ ] Test purchase completed if possible.
- [ ] Download link verified.
- [ ] Receipt email checked.
- [ ] License terms visible before purchase.

## Website Setup

- [ ] Landing page headline ready.
- [ ] Screenshot gallery added.
- [ ] Buy button linked.
- [ ] FAQ added.
- [ ] Requirements added.
- [ ] License summary added.
- [ ] Contact/support path added.
- [ ] Analytics configured if used.
- [ ] No unsupported claims on page.

## GitHub Setup

- [ ] Release notes drafted.
- [ ] README matches launch positioning.
- [ ] Screenshots linked.
- [ ] Known limitations clear.
- [ ] Installation instructions tested.
- [ ] License status clear.
- [ ] Public/private repository decision made.
- [ ] Tags created if releasing from GitHub.

## Final Pre-Publish Review

- [ ] No private names, paths, emails, or secrets in screenshots.
- [ ] No API keys in docs.
- [ ] No private sample documents.
- [ ] No unlicensed assets.
- [ ] No unsupported claims about perfect OCR or universal PDF support.
- [ ] No claims that it replaces enterprise document AI platforms.
- [ ] No promise of included support unless support is defined.
- [ ] Product title is consistent across listing, README, and screenshots.
- [ ] All purchase links work.
- [ ] First customer outreach list is ready.
