# Pricing Recommendation

RelayWorks AI Document Processing Kit should be priced as a commercial source-code product, not as a low-cost ebook or SaaS subscription. The buyer receives a working application baseline that can save days or weeks of setup time.

These prices are recommendations and should be tested against actual demand.

## Recommended License Tiers

### Personal License - $79

For one individual developer using the code for personal learning, prototypes, or one non-client project.

Suggested rights:

- One individual user.
- Personal projects or internal prototype use.
- Modify source code for permitted use.
- No client delivery.
- No redistribution.
- No resale.
- No team sharing.

Why $79:

- Low enough for individual developers to impulse-buy.
- High enough to signal this is a source-code product, not a tutorial PDF.
- Useful for first sales and feedback.

### Commercial License - $249

For one individual or business using the code in a commercial/internal workflow.

Suggested rights:

- One buyer or one small business entity.
- Internal business use.
- One production deployment or project.
- Modify source code for permitted use.
- No resale, sublicensing, or public redistribution.
- Contractor access only if explicitly allowed.

Why $249:

- A commercial buyer can justify this if it saves even a few hours of engineering time.
- It separates serious buyers from hobby users.
- It keeps the product accessible for founders, consultants, and internal-tool builders.

### Team License - $699

For teams that need multiple developers to access and modify the code.

Suggested rights:

- One company/team.
- Up to a defined number of developers, such as five seats.
- Internal repositories allowed.
- Internal deployment allowed.
- CI/CD copies allowed as needed for the licensed project.
- No resale or redistribution.
- Client delivery rights excluded unless separately purchased.

Why $699:

- Teams pay for reduced implementation time and shared code access.
- Still inexpensive compared with custom ingestion development.
- Creates room for discounting without collapsing perceived value.

## Optional Agency/Client-Work License

Recommended future tier: $1,499 to $2,499.

This should only be offered after the license language is final.

Potential rights:

- Use RelayWorks as a starting point for client document ingestion projects.
- Deliver deployed/compiled applications to clients.
- Limited number of client projects.
- No resale as a competing source-code template.
- No transfer of raw RelayWorks source unless explicitly allowed.

## Launch Discount

Suggested launch offer:

- 25% off for the first 10 buyers.
- Or fixed early-buyer price of $149 for the Commercial License.

Avoid permanent heavy discounts. The product depends on trust and source-code value, so extreme discounting can make it feel unfinished.

## Pricing Page Framing

Use practical value language:

- "Skip the blank-repo phase."
- "Start with upload, background jobs, exports, reports, and package downloads already wired."
- "Own the source code and adapt it to your stack."
- "PDF extraction quality still depends on Marker and source documents."

## What Not To Promise

Do not price or describe the product as if it includes:

- Managed hosting.
- Enterprise support.
- Perfect OCR.
- Every document format.
- Unlimited production scale.
- Authentication.
- Billing.
- Cloud storage integrations.
- Legal compliance guarantees.

## Recommended Starting Strategy

Start with:

- Personal: $79.
- Commercial: $249.
- Team: $699.

Then measure:

- Landing page visits.
- Gumroad conversion rate.
- Questions from buyers.
- Which tier gets clicked most.
- Whether buyers ask for agency rights.
- Whether installation support becomes a bottleneck.

If the first buyers are mostly agencies or consultants, add the higher client-work license. If buyers are mostly solo developers, keep Commercial as the primary tier and use Personal as an entry point.
